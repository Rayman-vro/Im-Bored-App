# Im-Bored-App
Shows a random activity to do when you're bored. Click a button to get a new one.

# Built with

- Python
- PyInstaller

# Download

1. Download `ImBored.exe`.
2. Double-click it to run. No Python needed.

Windows may show "Windows protected your PC" because the app is unsigned. Click "More info", then "Run anyway".

# How to use

1. Open the app and a random activity is shown
2. Click "Pick Another Activity" to get a new one
3. You can also press "Space" or "Enter" instead of clicking
